# Laboratory 5 – Cloud Data Engineer

## Mission Overview
Deployed an S3-compatible object storage server (MinIO) using Docker, created a storage bucket, and uploaded a test file to simulate a real-world photo storage backend.

## Objectives
- Differentiate between Block, File, and Object Storage
- Deploy MinIO using Docker
- Access the web console via port forwarding
- Create a bucket and upload objects
- Document the process in Markdown

## Tools Used
- Docker
- MinIO
- KillerCoda Playground
- GitHub

## Skills Learned
- Deploying containerized storage services
- Working with Docker environment variables
- Navigating a cloud storage web console
- Writing technical documentation in Markdown
