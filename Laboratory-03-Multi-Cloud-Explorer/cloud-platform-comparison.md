1. Which cloud platform impressed you the most?
GCP impressed me the most, especially its AI/ML tools and Kubernetes support, since Google created Kubernetes itself.

2. What similarities exist among AWS, Azure, and GCP?
All three offer similar core services (VMs, storage, databases, identity management), use pay-as-you-go pricing, and operate in multiple global regions.

3. How do business requirements influence cloud platform selection?
The right platform depends on the client's needs — like Azure for Microsoft-based companies, or GCP for AI-focused ones — not just which provider is most popular.

4. What did you learn from acting as a Cloud Solutions Consultant?
I learned to match a platform's strengths to a client's actual problem instead of just picking the most well-known option.

5. How has your GitHub Cloud Computing Portfolio improved after completing this mission?
My portfolio now shows I can compare multiple cloud providers and organize technical documentation clearly using Markdown, tables, and screenshots.
