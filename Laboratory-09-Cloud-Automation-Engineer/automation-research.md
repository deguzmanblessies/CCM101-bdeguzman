# Automation Research: The Language of Automation

## Bash Script
A Bash script is a text file that contains a list of Linux commands that run one after another, so I don't have to type them manually. The first line, `#!/bin/bash` (the shebang), tells Linux to use the Bash program to run the file.

## Variables
A variable stores a value, like a folder path, under a name such as `$BACKUP_DIR`. Programmers use them so they only have to change the path in one place instead of editing it everywhere in the script. This also makes the script shorter, cleaner, and less likely to have typing mistakes.

## Cron Job
A cron job is a task that Linux runs automatically at a set time or schedule, like every night at 2:00 AM. It is essential in cloud operations because tasks like backups, updates, and cleanups happen on time without anyone having to remember them.
