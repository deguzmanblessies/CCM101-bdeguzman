# Cloud Provider Comparison

| Infrastructure Component | AWS | Microsoft Azure | Google Cloud Platform |
|---|---|---|---|
| Compute | Amazon EC2 | Azure Virtual Machines | Compute Engine |
| Storage | Amazon S3 | Azure Blob Storage | Google Cloud Storage |
| Networking | Amazon VPC | Azure Virtual Network (VNet) | Google VPC |
| Identity and Access Management (IAM) | AWS IAM | Microsoft Entra ID (Azure AD) | Google Cloud IAM |

## Guide Questions

1. **Which cloud provider offers the broadest range of services? Explain your answer.**
AWS is generally considered to offer the broadest range of services, since it was the first major public cloud provider and has continuously expanded its catalog across compute, storage, AI/ML, IoT, and more.

2. **Which cloud platform would you recommend for an organization that primarily uses Microsoft products? Why?**
Microsoft Azure, because it integrates natively with Windows Server, Active Directory, Microsoft 365, and other Microsoft tools, reducing compatibility and licensing friction.

3. **Which platform is widely recognized for AI, ML, and Kubernetes services?**
Google Cloud Platform, since Google originated Kubernetes and has strong AI/ML tooling (Vertex AI, TensorFlow origins).

4. **What similarities did you observe among the three cloud providers?**
All three offer the same core categories of services — compute, storage, networking, and IAM — under different names, follow a pay-as-you-go pricing model, and provide global data center regions for scalability and redundancy.
