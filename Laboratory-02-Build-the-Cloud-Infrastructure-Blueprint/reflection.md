1. Which cloud infrastructure component do you think is the most important? Why?
I think storage is the most important because all the data a company relies on lives there, and losing it would be worse than any other failure. Compute and networking can be rebuilt or reconfigured, but lost data is often gone for good.

2. How does Linux support cloud computing?
Linux is lightweight, free, and highly customizable, which is why most cloud servers run on it instead of paid operating systems. It also has strong command-line tools that make it easy to automate and manage servers remotely.

3. Why is technical documentation important before deploying infrastructure?
Documentation helps the team understand exactly what's being built and why, so nothing gets deployed based on guesswork. It also makes it easier to fix problems later, since you can look back and see how the system was set up.

4. What new skills did you learn during this laboratory activity?
I learned how to check a Linux server's specs using terminal commands like lscpu and free -h. I also got more comfortable comparing cloud providers and organizing technical documentation in Markdown.
