# Laboratory 2 – Build the Cloud Infrastructure Blueprint

## Mission Overview
This lab investigates the core components of cloud infrastructure (compute, storage, networking, identity)
using a Linux environment provisioned on KillerCoda, and documents findings as technical documentation.

## Objectives
- Explain the major components of cloud infrastructure
- Investigate hardware/software resources in a Linux environment
- Differentiate compute, storage, networking, and identity resources
- Compare major cloud providers
- Produce Markdown-based technical documentation

## Cloud Infrastructure Components
See [cloud-components.md](./cloud-components.md) for details on compute, storage, networking, and OS.

## Tools Used
- KillerCoda Playground (Linux environment)
- GitHub (version control & documentation)
- Draw.io (architecture diagram)

## Linux Commands Executed
`cat /etc/os-release`, `uname -r`, `lscpu`, `free -h`, `df -h`, `mount`, `hostname`, `ip a`

## Skills Learned
- Inspecting a Linux server for hardware/OS/network specs
- Mapping Linux resources to cloud infrastructure concepts
- Comparing AWS, Azure, and GCP services
- Writing structured technical documentation in Markdown
